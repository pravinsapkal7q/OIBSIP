# Oasis Infobyte Data Analytics Internship

## Task 1: Exploratory Data Analysis (EDA) on Retail Sales Data

**Intern Name:** Pravin Sapkal

### Objective
To analyze retail sales data and understand customer behavior, sales trends, and product category performance.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Dataset
The dataset contains 1,000 retail transactions and 9 columns, including customer age, gender, product category, quantity, price per unit, and total amount.

### Analysis Performed
- Dataset inspection and missing-value analysis
- Statistical summary
- Sales by product category
- Monthly sales analysis
- Gender analysis
- Age group analysis
- Correlation heatmap

### Key Findings
- The dataset contains 1,000 transactions.
- No missing values were found.
- The average customer age is approximately 41 years.
- The average transaction amount is 456.
- Sales performance was compared across product categories and customer groups.

### Conclusion
This project uses Exploratory Data Analysis to understand retail sales patterns and customer behavior. Python libraries were used to analyze the data and create visualizations.

### How to Run
1. Open the project folder in VS Code.
2. Open `EDA_Retail_Sales.ipynb`.
3. Run all cells using **Run All**.
