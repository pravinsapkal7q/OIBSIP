# 🍷 Wine Quality Prediction using Machine Learning

## 🏢 Oasis Infobyte - Data Analytics Internship
### Level 2 - Task 2

---

### 📌 Project Overview
The goal of this project is to analyze the physicochemical properties of red wine and build supervised machine learning classification models to predict whether a wine is of high quality or average/bad quality.

### 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Environment:** Google Colab / Jupyter Notebook

---

### 📊 Exploratory Data Analysis & Visualizations
1. **Quality Distribution:** Visualizes the class imbalance in wine quality scores.
2. **Correlation Heatmap:** Shows how chemical properties like alcohol, volatile acidity, and sulphates affect wine quality.
3. **Feature Importance:** Highlights the most dominant factors influencing wine grading using Random Forest.

---

### 🤖 Machine Learning Models & Results
We trained and evaluated three classification models using a stratified 80/20 train-test split:
* **Random Forest Classifier** 
* **Support Vector Classifier (SVC)**
* **Stochastic Gradient Descent (SGD Classifier)**

---

### 🔑 Conclusion
Alcohol content and volatile acidity were identified as the key determinants of wine quality, with Random Forest delivering robust classification performance.
